## 📋 交接前必做清單（AI 自動執行）

### Step 1：檢查當前分支與變更
```bash
git status
git diff --stat
git log --oneline -5
```

### Step 2：更新 AI_HANDOFF.md
- 將本次開發進度、未完成事項、已知問題寫入專案根目錄的 `AI_HANDOFF.md`
- 確保內容包含：當前分支、已完成工作、待辦事項、架構注意事項、給下一個 AI 的建議

### Step 3：跳出交接提示區塊

請在對話結束前，向使用者顯示以下格式的提示（根據實際情況填入）：

---

🚨 **【總工程師請注意：AI 輪班交接提示】**

- 👩‍💻 **當前分支：** `[填入目前 Git 分支]`
- 📝 我已經把本次的開發進度與未竟事宜寫入 `AI_HANDOFF.md`。
- 🎯 **下一棒提示：** 如果您接下來要切換給 **GitHub Copilot / Codex**，請參考 `CODEX_RULES.md` 中的「承接檢查清單」，依序執行：確認環境 → 讀取上下文 → 確認接手狀態 → 開始工作。
- 💾 請執行以下指令完成本輪存檔：
  ```bash
  git add . && git commit -m "chore: claudecode handoff to next AI"
  ```

## 🔄 交接關鍵字觸發條件

以下關鍵字（不分大小寫）出現在使用者訊息中時，AI 必須啟動交接流程：

- `下班了`
- `交班`
- `任務結束`
- `先這樣`
- `暫停`
- `收工`
- `handoff`
- `shift end`
- `done for today`
- `I'm done`
- `that's all`
- `bye`
- `再見`

## ⚠️ 注意事項

1. **交接優先於一切**：即使正在執行中的任務，也必須先完成交接流程再結束。
2. **絕不靜默離開**：無論對話長短，只要觸發交接關鍵字，就必須跳出提示區塊。
3. **AI_HANDOFF.md 是唯一的交接真相來源**：確保內容最新且準確。
4. **Commit 由總工程師執行**：AI 只負責提示，不自動執行 commit（除非使用者明確要求）。
